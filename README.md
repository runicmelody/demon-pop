## Demon Pop (Godot 4.4)

Arcade-style 3D arena shooter prototype built with **Godot 4.4**.

### Requirements

- **Godot Engine 4.4 or newer** (Standard/Mono, any edition that can open `.godot` project files)
- Desktop OS (project is configured with `config/features = "4.4", "Mobile"` but is primarily developed/tested on PC)

### Project structure

- **`project.godot`**: Main Godot project configuration (open this file with the Godot editor).
- **`level/`**: Main game scenes and scripts (e.g. `game.tscn`, `world.tscn`, `main_menu.tscn`).
- **`player/`**: Player models, scenes and scripts.
- **`mob/`**: Enemy scenes, spawners and visual effects.
- **`gdscript.pck` / `gdscript.exe`**: Exported build of the game for Windows (generated by Godot).

### How to open the project in Godot

1. Launch **Godot 4.4**.
2. In the project manager, click **Import**.
3. Browse to this folder: `C:\Users\FARUK\Documents\gdscript` (or the cloned repo path).
4. Select `project.godot` and click **Import & Edit**.

### How to run the game from the editor

- Press **F5** or click the **Run Project** ▶ button in the top-right of the Godot editor.
- The project is configured to use `level/game.tscn` (via the `run/main_scene` value in `project.godot`) as the startup scene.

### Controls (default)

Configured in `project.godot` under the **[input]** section:

- **W / A / S / D**: Move (forward / left / backward / right).
- **Mouse Left Button**: Shoot.
- **R**: Reset (as defined in input actions).
- **T**: Toggle/trigger `killermode` (developer/debug action).
- Additional actions like `acceleration` are bound to extra keys and can be tuned in the Godot Input Map.

### Running the exported build (Windows)

If you do **not** want to open Godot, you can use the exported build:

1. Make sure `gdscript.exe` and `gdscript.pck` are in the **same directory**.
2. Double-click **`gdscript.exe`** to start the game.

> **Note:** `gdscript.exe` is a large binary (~90 MB) and may trigger size warnings on Git hosting platforms. For long-term use, consider using **Git LFS** or excluding editor-generated exports from version control.

### Development notes

- Ignore folders/files listed in `.gitignore` (e.g. `.godot/`, `.import/`, exports, temporary editor files).
- When adding new input actions, use **Project → Project Settings → Input Map** in the Godot editor, then commit the updated `project.godot`.
